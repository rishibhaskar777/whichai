# Roadmap

Each phase ends with a working, deployed-quality increment. Do not start a phase before the previous one passes its checks.

## Phase 1: Foundation and home page

- Repository, tooling, CI, security baseline
- Design tokens and base layout (sidebar, centre, news panel)
- Home page with search input, suggestion chips, sample news panel
- Light and dark themes, responsive layout, reduced-motion support
- No backend features. The search input does not send data anywhere yet.

## Phase 2: Understanding step and plan page

- Understanding card with editable chips
- Plan page with Simple, Polished and Advanced levels using sample data
- Free, Pro and Max comparison block, workflow, starter brief

## Phase 3: Data and rules engine

- Database schema and migrations
- Tool, job and goal-template data with verified dates and sources
- Rules engine and tests
- Extraction endpoint with schema validation and rate limiting

## Phase 4: Accounts and feedback

- Authentication through a maintained library
- Saved plans and search history
- One-tap feedback with minimum-response thresholds

## Phase 5: News and updates

- Official-source monitoring script and review workflow
- News panel and What Changed page backed by real data
- Alerts for saved plans affected by changes

## Later

Tool library, plan comparison pages, test results pages, pricing, institution features.
